# Искра — мессенджер

Простой мессенджер: сервер на чистом Python (без установки библиотек) и один файл клиента в браузере.

## Файлы проекта

Все три файла должны лежать **в одной папке**:

```
server.py      — сервер (запускается)
index.html     — клиент (открывается сам через сервер)
data.json      — база данных (создаётся сама при первом запуске, если её нет)
```



## Требования

- Установленный **Python 3.8 или новее**. Проверить: `python --version` (на Mac/Linux иногда `python3 --version`).
- Больше ничего ставить не нужно — сервер использует только стандартную библиотеку.




.

## Вход в мессенджер

1. Вводишь номер телефона.
2. Если номер уже зарегистрирован — просит пароль.
3. Если номер новый — просит придумать имя и пароль (не короче 8 символов).

SMS не используются — только номер и пароль.
